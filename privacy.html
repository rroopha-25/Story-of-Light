The Story of Light

Privacy policy

Last updated: 8 November 2026

In shortThis website does not ask for an account, does not use cookies, does not run analytics or ads, and does not collect or store any personal information on a server.

What this website is

The Story of Light is a free, static website that retells the Ramayana for Diwali. It is hosted on GitHub Pages and has no database or server-side code of its own.

Information we collect

We do not collect any personal information. There are no sign-ups, forms that send data, cookies, tracking pixels or analytics tools on this site.

The name you type in the wish

  • If you type a name into the "Happy Diwali" wish, it is used only inside your own browser to show the wish.
  • The name is also added to the end of the page address (after the # sign) so you can share a personal link. The part after # is never sent to the web server.
  • Anyone you share that link with can see the name in it. If you don't want to share a name, leave the box empty.

Music and narration

Music is generated inside your browser. Narration uses your device's built-in text-to-speech voice. Some browsers, such as Google Chrome with certain online voices, may send the narration text to the browser maker to produce speech. That is handled by your browser under its own privacy policy. The narration text is only the story itself, never anything you typed.

Third-party services

  • GitHub Pages hosts the website. Like any web host, GitHub may log technical information such as IP addresses to keep the service secure. See the GitHub General Privacy Statement.
  • Google Fonts provides the typefaces. Your browser downloads them from Google's servers. See the Google Fonts privacy FAQ.
  • Google Maps opens only if you tap an "Open in Google Maps" button. Google's own privacy policy then applies.

Children

The site is suitable for families and does not knowingly collect information from anyone, including children.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact
